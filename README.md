# Retail Customer Sales Analysis

## Project Overview
This project focuses on Exploratory Data Analysis (EDA) of a retail customer sales dataset using Python. The aim is to understand customer purchasing behaviour, sales performance, profitability and delivery trends.

## Objectives
- Understand and explore the retail sales dataset.
- Clean and preprocess the data.
- Identify missing values and duplicate records.
- Perform descriptive statistical analysis.
- Create visualizations to identify sales trends.
- Generate meaningful business insights.

## Tools and Technologies
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Structure
- **CODE:** Python notebook, datasets, visualizations and insights report.
- **SYNOPSIS:** Project synopsis document.

## Key Findings
- East region recorded the highest total sales.
- Electronics generated the highest total profit.
- Corporate customers had the highest average transaction sales.
- Net Banking was the most frequently used payment method.
- Express delivery had the shortest average delivery time.
